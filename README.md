# kushal-gangadhar.github.io

Personal portfolio website for Kushal Gangadhar, built as a single-page static site.

## Overview

This repository hosts the source for a GitHub Pages portfolio website.  
The site includes:

- Intro/hero section
- About section
- Projects (personal and academic)
- CV download link
- Personal interests section
- Contact and social links

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript

## Project Structure

- `/tmp/workspace/kushal-gangadhar/kushal-gangadhar.github.io/index.html` — main page with markup, styles, and scripts

## Run Locally

Because this is a static site, you can open `index.html` directly in a browser, or serve it locally:

```bash
cd /tmp/workspace/kushal-gangadhar/kushal-gangadhar.github.io
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

This repository is intended for GitHub Pages deployment from the default branch.
